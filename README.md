# 自定义动态桌宠图案制作指南

本文介绍两种方案，将一段短视频处理成带有透明通道的动态 GIF，作为自定义桌宠图案。整体流程分为“获取视频素材 → 裁剪视频 → 抠图并转换为 GIF”三步，其中抠图转换环节提供两种实现方式。
---
<img src="https://raw.githubusercontent.com/xiaowuf/User-definded--/main/PUNI.png"width="25%" alt="PUNI">
## 一、准备视频素材

1. 挑选一张你喜欢的照片（角色或物体），没有的话可以参考本项目的PUNI.png。
2. 将照片发给**豆包**，让它生成一段 **3 秒、1:1 比例**的视频。  
   - 需要自行用文字描述你想要的动作（如：挥手、跳动、旋转等）。
3. 保存生成的视频，得到类似 `pn1.MP4` 的原始素材（也可以直接使用本项目提供的 `pn1.MP4`）。
---

## 二、裁剪视频

运行项目中的 `Video_clipping.py` 对原始视频进行裁剪，去除多余部分，使主体居中且尺寸符合后续处理要求。

- **使用方法**：修改脚本里的文件路径，将输入视频指向你的 `pn1.MP4`，输出命名为 `pn2.MP4`。  
- 如果需要使用项目自带的示例视频，记得将路径调整为实际存放位置。

> 完成后你将得到裁剪好的 `pn2.MP4`。

---

## 三、抠图并转换为 GIF（两种方案）

### 方案一：使用 `Image_masking_white.py`

该脚本专门用于白色背景（或其他纯色背景）视频的抠图，并直接输出 GIF。

- **优点**：无需额外安装软件，依赖纯 Python 库（如 OpenCV、Pillow）。
- **操作**：  
  1. 将脚本中的输入路径改为 `pn2.MP4`。  
  2. 运行脚本，等待处理完成。  
  3. 输出即为带透明背景的动态 GIF 桌宠图案。

### 方案二：使用 `test.py`（需安装 FFmpeg）

`test.py` 同样可以实现抠图与 GIF 转换，但依赖于 **FFmpeg** 工具。若你尚未安装 FFmpeg，请按以下步骤操作：

#### 1. 下载 FFmpeg
- 打开 [FFmpeg 官方构建页面](https://www.gyan.dev/ffmpeg/builds/)。
- 找到 **“Release builds”** 区域，选择 **`ffmpeg-release-essentials.zip`**（该版本包含可直接运行的 `ffmpeg.exe`）。
- 建议下载页面上的**最新版本（Latest Release）**。

#### 2. 解压并放置
- 将下载的 ZIP 文件解压，例如解压到 `C:\ffmpeg`。  
- 确保解压后的目录结构类似 `C:\ffmpeg\bin\ffmpeg.exe`。

#### 3. 配置环境变量
- 打开“此电脑” → 右键 → “属性” → “高级系统设置” → “环境变量”。
- 在 **系统变量** 中找到 `Path`，选中后点击“编辑”。
- 点击“新建”，输入 `C:\ffmpeg\bin`，然后确定保存。

#### 4. 验证安装
- 打开一个新的命令提示符窗口（Win+R，输入 `cmd`）。
- 输入以下命令并回车：
  ```bash
  ffmpeg -version
